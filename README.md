# 🌋 제주 3D 관광 지도

three.js(WebGL)로 만든 제주 입체 지도. 한라산·오름·해안·풍력발전기·등대·돌하르방을 3D로 보고, 공공데이터포털의 **서귀포시 직영관광지 관람객수 추이**를 지도 위 막대(월별 애니메이션)로 탐색합니다.

- 회전/확대/이동: 마우스 드래그 · 휠 · 우클릭 드래그 (모바일은 터치/핀치)
- 시점 버튼: 전체 / 한라산 / 서귀포 관광지 / 성산·우도 / 서쪽 해안
- 레이어 토글: 방문자 막대, 한라산·오름, 항·포구, 올레길(개략), 감귤 재배지, 풍력발전기, 등대, 돌하르방, 구름
- 아래 타임라인: 월 선택·재생 → 관광지별 막대 높이가 변하고 순위·추이 그래프가 갱신됨

## 실행

```bash
npm install
cp .env.example .env     # PowerShell: Copy-Item .env.example .env  → DATA_GO_KR_KEY 입력
npm run dev              # http://localhost:5173
```

## Vercel 배포

1. GitHub에 올린 뒤 https://vercel.com/new 에서 Import (Framework: Vite 자동 인식)
2. Environment Variables: `DATA_GO_KR_KEY` = 공공데이터포털 일반 인증키 (Production/Preview/Development 모두, 앞뒤 공백·따옴표 없이)
3. Deploy. 환경변수를 바꾼 뒤에는 Redeploy.

인증키는 서버리스 함수 `api/visitors.js` 에서만 사용되어 브라우저에 노출되지 않습니다. 키가 없어도 3D 지도는 보이고 방문자 막대만 비어 있습니다.

## 알아둘 점

- 지형은 실제 지도(DEM)가 아니라 **좌표와 대략적인 모양으로 만든 단순화 모델**이며, 세로는 보기 좋게 과장했습니다. 장소 위치도 대략적입니다.
- 올레길은 해안을 따라 도는 **개략도**이고 실제 노선이 아닙니다. 풍력발전기·등대·돌하르방은 크기를 과장했습니다.
- 방문자 데이터는 서귀포시 직영관광지 6곳(천지연폭포, 정방폭포, 천제연폭포, 중문대포 주상절리대, 산방산_용머리, 감귤박물관)이며, 빈칸은 "미집계"로 표시합니다.
- 출처: 공공데이터포털, 제주특별자치도 서귀포시_직영관광지 관람객수 추이 (이용허락범위는 데이터 상세 페이지 확인)
